Cree un token de uso para quien consuma nest-api (integrador, partner, servicio interno). Canal y subcanal se guardan en la key y se usan en emisión/cobranza (Sis2000) al igual que en metadata SSO.
Catálogos INMA / valrep solo requieren token válido — no marque endpoints. Elija cada endpoint que el cliente pueda usar (emisión, cobro, documentos, partner…). Puede marcar solo algunos de un mismo módulo (ej. cobrar sin notificar).
